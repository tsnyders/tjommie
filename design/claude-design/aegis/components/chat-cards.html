Approval and exchange cards

An approval is the one raised card in a thread: what the agent wants, the exact command, its autonomy, and two answers. Approve is the near-black pill; Deny is an underlined text action, so the safe answer is never the loud one by accident. Agent-to-agent exchanges fold into a card with both voices.

Autonomy, what the agent may do without asking

AskAlways ask: asks before every change it makes. FolderOwn folder: works freely inside its own folder and asks before anything else. FullFull auto: never asks. It can run any command and change any file your Windows account can.
